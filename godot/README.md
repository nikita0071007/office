# Office Agents 3D Preview

This Godot project opens a real-time 3D office scene with an interactive camera and a photo-based first view of Lisa.

Open the `godot` folder in Godot 4 and run `Main.tscn`. Drag with the left mouse button to orbit, use the wheel to zoom, and use the reset button to restore the starting view.

The room uses low-poly box meshes and Godot's Compatibility renderer. Lisa is currently a transparent billboard image, so the project remains lightweight while a true 3D character model is unavailable.
